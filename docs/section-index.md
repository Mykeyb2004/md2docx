# 二级标题索引页

在 GUI 主界面勾选「插入二级标题索引页」即可生效，开关自动记住下次使用。也可在「编辑配置 → 文档」或 YAML 中设置：

```yaml
document:
  section_index: true
```

默认值为 `false`，旧配置没有该字段时保持原来的转换结果。命令行通过 `--style-file` 加载配置；Python API 可通过 `config_override` 或 `config_data` 设置相同字段。

## 样式和保存

直接使用现有「一级～四级标题」转换配置：索引页标题使用 `heading2`，三级条目使用 `heading3`，四级条目使用 `heading4`。一级标题配置仍供正文使用，不额外加入索引。

复用字体、字号、颜色、粗体、斜体、对齐、首行缩进、段前段后距及行距；字号支持 `10.5pt`。标题未指定行距时索引使用 `document.line_spacing`（缺省为 1.5）。独立分页、双线框、框内垂直居中及三级标题与首个四级条目保持相邻由索引模块处理。

在编辑器中「保存」或「另存为」后，所有一级～四级标题设置都写入 YAML；应用记住配置路径，下次启动重新载入。主界面开关立即生效，单独保存在偏好中，不自动改写用户的 YAML。打开编辑器时会带入当前开关，保存时一并写入 YAML；打开其他配置或保存编辑器后，主界面与该配置同步。

保留已确认样例的页面结构，文字排版以用户配置为准。需要参考图中的居中效果时，将二～四级标题的对齐设为「居中」、首行缩进设为 0；分组留白可通过三级标题的段前距调整。

## 生成规则

- 每个二级标题前另起索引页，顶部显示该二级标题；下方用双线矩形框展示所属三级、四级标题，整组在框内垂直居中，文字样式来自对应标题配置。
- 遇到下一个一级或二级标题时结束当前节。五级、六级标题不纳入索引，即使正文将它们显示为 Word 的四级标题样式。
- 索引条目不显示页码，也不需要更新目录域；模板页脚中的页码正常保留。索引条目可跳转到正文对应标题；同名标题仍有独立目标。
- 没有三级、四级标题时，保留只显示二级标题的索引页。
- 索引独立于正文，正文中的二级标题另起一页。长索引自动续页，不截断条目。
- 索引文字保留原标题内容，作为普通段落写入，不重复进入 Word 导航窗格或总目录。参考图中的蓝色换行标记是编辑器辅助标记，不会写入。
- 文档有 Markdown 章节标题（`##`～`######`）时，只使用 Markdown 标题结构生成索引；正文中的 `一、`、`（一）` 等中文编号保留原排版，不生成额外索引页，也不截断章节索引。
- 没有 Markdown 章节结构时，兼容现有中文大纲识别结果；允许文档开头只有 `#` 总标题。此时中文大纲层级沿用识别器定义：`一、` 为一级、`（一）` 为二级、`1.` 为三级、`（1）` 为四级，与配置中选择的外观样式无关。
- 直接在载入的 Word 模板文档中插入，保留页面尺寸、页边距、页眉页脚距离、首页/奇偶页设置、页码域及起始页码，不额外创建节。模板仍遵循转换器现有的单节限制。

## 实现与影响分析

渲染器按顺序记录标题的语义层级及段落引用；`Converter.to_document()` 在正文和元数据完成后按开关调用独立的 `section_index` 模块。该模块单次分组，插入普通段落、内部书签及跳转链接，不重新解析 Markdown。每次转换创建新的渲染器，记录不会跨文档累积。

渲染器另行记录 Markdown 标题来源，转换入口据此选择单一章节结构。这样可避免中文正文小标题被误当成独立章节、生成仅有标题的索引页并强制分页。回归测试覆盖自动/强制中文大纲识别、有/无 Word 模板、正文段落格式不变、索引跨中文编号持续收集，以及纯中文大纲和转换器重复使用。
