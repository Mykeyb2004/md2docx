# GUI 使用指南

## 启动 GUI 应用

### 方法1：命令行启动

```bash
# 使用 uv
uv run md2docx-gui

# 或通过 uv 运行 Python 模块
uv run python -m md2docx.gui
```

### 方法2：Python 代码启动

```python
from md2docx.gui import main

main()
```

## 功能说明

### 📂 文件转换

1. **选择 Markdown 文件**
   - 点击 "浏览..." 按钮
   - 选择 `.md` 文件
   - 自动建议输出文件名

2. **指定输出文件**
   - 点击 "另存为..." 按钮
   - 或直接修改输出路径

3. **可选 Word 模板**
   - 在 "Word 模板" 行点击 "选择..." 选择 `.docx` 模板
   - 模板会保留页眉、页脚中的文字、图片和格式；点击 "清除" 可取消套用

4. **执行转换**
   - 点击 "转换为 Word" 按钮
   - 查看进度条和状态
   - 完成后显示成功提示

### 配置文件

**自动恢复**：
- 应用启动时自动载入上次成功打开或保存的 YAML 配置
- 上次配置不存在或无法读取时，回退到内置默认配置并显示警告
- 当前配置未关联文件时，界面显示“内置默认（未关联文件）”

**打开配置**：
- 点击“打开配置...”选择 `.yaml` 或 `.yml` 文件
- 只有文件成功读取后，才会替换当前配置并记录为下次启动配置
- 打开失败不会改变当前配置或上次配置记录

**编辑与保存**：
- 点击“编辑配置...”修改当前配置
- “保存”覆盖当前关联文件；内置默认尚未关联文件时会转为“另存为”
- “另存为”写入新文件，并将新文件切换为当前配置
- “另存为”若选回当前文件，仍会执行外部修改检测；选择其他已有文件时由文件选择器确认覆盖
- “恢复内置默认”只更新编辑草稿，仍需保存后才会用于转换
- 转换始终使用最近一次成功载入或保存的配置，未保存草稿不会参与转换

**关闭与冲突处理**：
- 关闭含未保存修改的编辑器时，可选择“保存”“放弃”或“取消”
- 关闭主窗口或退出应用时，也会先执行编辑器的未保存确认；选择“取消”会保留应用
- 若配置文件被其他程序修改，保存时可选择“重新载入”“覆盖”或“取消”
- 配置保存采用原子替换；写入失败时保留原文件和当前草稿，可修复问题后重试

### 📜 历史记录

**自动保存**：
- 每次转换自动记录
- 保存位置：`~/.md2docx/history.json`
- 最多保留 100 条记录

**查看历史**：
- 表格显示转换时间、文件名、状态
- 成功记录显示为绿色
- 失败记录显示为红色

**重新使用**：
- 双击历史记录
- 或选中后点击 "重新载入选中记录"
- 自动填充输入和输出路径

**清空历史**：
- 点击 "清空历史记录"
- 确认后清空所有记录

## 历史文件格式

历史记录保存为 JSON 格式：

```json
[
  {
    "time": "2025-11-20 12:00:00",
    "input": "/path/to/input.md",
    "output": "/path/to/output.docx",
    "status": "Success"
  }
]
```

**字段说明**：
- `time` - 转换时间
- `input` - 输入文件完整路径
- `output` - 输出文件完整路径
- `status` - 转换状态（Success 或 Failed: xxx）

## 常见问题

**Q: GUI 无法启动？**  
A: 确保安装了 tkinter（Python 3 通常自带）

**Q: 如何查看完整文件路径？**  
A: 将鼠标悬停在历史记录上（可扩展添加 tooltip）

**Q: 历史记录保存在哪里？**  
A: `~/.md2docx/history.json`

**Q: 可以同时转换多个文件吗？**  
A: 当前版本仅支持单文件转换，可扩展添加批量转换功能
